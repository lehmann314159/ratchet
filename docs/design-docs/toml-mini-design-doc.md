# toml-mini — Design Document

## Overview

`toml-mini` is a Go library that both **parses** a small TOML subset into a
nested map and **serializes** a nested map back to canonical TOML text. It is a
symmetric read/write pair: the point is the round-trip, `Parse(Encode(m))` deep-
equals `m` and `Encode(Parse(s))` is the canonical form of `s`. A CLI (`main.go`)
reads a TOML document on stdin and either reformats it (`reformat`) or prints a
sorted flat key dump (`dump`).

Consumers: config-file loading in application code. Runtime model: **library**
plus a **CLI** harness. No server, no file I/O beyond stdin/stdout, no
third-party TOML package.

**The supported subset — everything else is a syntax error, do not extend it:**

- **Values** are exactly: basic strings, integers, booleans, and single-line
  homogeneous arrays (which may nest).
  - **Basic string**: double-quoted. The **only** escapes are `\n`, `\t`, `\"`,
    `\\`. Any other backslash escape, an unescaped `"` inside the body, an
    unterminated string, or a literal newline inside → syntax error. No literal
    strings (`'...'`), no multi-line strings (`"""..."""`), no `\uXXXX`.
  - **Integer**: optional single leading `-`, then one or more decimal digits.
    No `+`. No underscores (`1_000`). No leading zeros beyond a lone `0`
    (`007` is an error). No hex/octal/binary. Range is `int64`; out of range →
    syntax error. `-0` parses to `0`.
  - **Boolean**: the literals `true` and `false` only.
  - **No floats.** `1.5` is a syntax error.
  - **Array**: `[` … `]`, comma-separated, **all on one line** (no line breaks
    inside). A single trailing comma is allowed (`[1, 2, ]`). `[]` is a valid
    empty array. Elements are parsed as values, so arrays nest (`[[1], [2, 3]]`).
    **Homogeneous**: every element must have the same Go dynamic type as the
    first (`string` / `int64` / `bool` / `[]any`); `[1, "a"]` is an error.
    Nested arrays all count as type `[]any` regardless of their contents.
- **Tables**: a `[header]` line, then `key = value` lines until the next header
  or EOF. `[a.b.c]` is a nested table (`root["a"]["b"]["c"]`). Keys before any
  header go into the root map.
- **Bare keys only**: `[A-Za-z0-9_-]+`, on both sides — `[my-table]`,
  `my_key = 1`. No quoted keys (`"my key" = 1`), no dotted keys in an assignment
  (`a.b = 1` is a syntax error — only `[a.b]` headers nest).
- **Comments**: a `#` **as the first non-whitespace character** makes the whole
  line a comment. There are **no inline comments** — `k = 1 # note` is a syntax
  error (the value text is `1 # note`, which is not a valid integer).
- **Duplicate rules**: the same bare key twice in the same table → error. The
  same `[header]` string twice → error. A `[header]` whose path steps through a
  key already bound to a scalar/array → error.
- **Whitespace**: leading/trailing spaces on a line and around `=` and inside
  `[...]` are trimmed. Tabs and spaces are equivalent as separators.

**Parsed value domain (see the parse -> encode Cross-Bead Contract):** a parsed value is always one
of `string`, `int64`, `bool`, `[]any` (homogeneous), or `map[string]any` (a
nested table). `Encode` accepts exactly these dynamic types and returns
`ErrType` for anything else (`int`, `float64`, `nil`, a struct).

**Out of scope:** inline tables `{ x = 1 }`; arrays of tables `[[x]]`;
datetimes; float values; multi-line arrays or strings; literal strings; unicode
escapes; comment preservation through the round-trip; reading or writing files.

## Architecture

```
toml-mini/
├── lexer.go      — lexLine, bareKeyOK, type lineKind + constants
├── strvalue.go   — unquote, quoteString  (the escape set, both directions)
├── scanvalue.go  — scanValue, scanInt, scanArray, splitTopLevel
├── parse.go      — Parse, descend
├── encvalue.go   — encodeValue
├── encode.go     — Encode, encodeTable
├── main.go       — func main, run(mode, in), flatten  — the CLI
└── *_test.go     — one test file per source file above, plus integration_test.go
```

All `.go` files use `package main` at the project root — one flat package, no
subdirectories. Module name is `tomlmini`. `go.mod` and
`do_not_use_this_test.go` are generated by scaffolding.

**File assignment rules (strict):**

- `lexer.go` contains `lexLine`, the unexported `bareKeyOK`, and `type lineKind`
  with its constants `lineBlank` / `lineHeader` / `lineKV`. No value parsing.
- `strvalue.go` contains exactly `unquote` and `quoteString`. This is the single
  source of truth for the escape set; no other file decides which characters
  are escaped.
- `scanvalue.go` contains `scanValue` and its helpers `scanInt`, `scanArray`,
  `splitTopLevel`. It calls `unquote` from `strvalue.go`. It does **not**
  contain the map-building logic.
- `parse.go` contains `Parse` and the unexported `descend`. It drives `lexLine`
  and `scanValue`; it does not re-implement line classification or value
  parsing.
- `encvalue.go` contains exactly `encodeValue`. It calls `quoteString`.
- `encode.go` contains `Encode` and the unexported `encodeTable`. It calls
  `encodeValue`.
- `main.go` contains `func main()`, `run(mode string, in io.Reader) string`, and
  the unexported `flatten`.
- Do **not** put `unquote`/`quoteString` anywhere but `strvalue.go`. Do **not**
  put the map-navigation (`descend`) in `scanvalue.go`. Do **not** put
  `encodeValue` logic inside `Encode` — `encode.go` calls it.

## Data Types and Function Signatures

All `.go` source files use `package main`. Module name is `tomlmini`. Requires
Go 1.22.

```go
// ---- lexer.go ----

type lineKind int

const (
	lineBlank  lineKind = iota // blank line or full-line comment
	lineHeader                 // [a.b.c]
	lineKV                     // key = value
)

// lexLine classifies one physical line. For lineHeader, path holds the dotted
// segments. For lineKV, key is the bare key and rawValue is the trimmed text
// after the first '='. err is ErrSyntax for a malformed line.
func lexLine(line string) (kind lineKind, path []string, key string, rawValue string, err error)

func bareKeyOK(s string) bool

// ---- strvalue.go ----

// unquote decodes a basic double-quoted string. Escapes: \n \t \" \\ only.
func unquote(s string) (string, error)

// quoteString wraps s in double quotes, escaping \ " newline tab and nothing else.
func quoteString(s string) string

// ---- scanvalue.go ----

// scanValue parses one RHS value string into string, int64, bool, or []any.
func scanValue(raw string) (any, error)

func scanInt(raw string) (any, error)
func scanArray(raw string) (any, error)

// splitTopLevel splits s on commas not inside a nested [] or a "" string,
// dropping one optional trailing empty field.
func splitTopLevel(s string) ([]string, error)

// ---- parse.go ----

// Parse reads a whole document into a nested map[string]any.
func Parse(doc string) (map[string]any, error)

// descend walks/creates root[path[0]][path[1]]... and returns the final table.
func descend(root map[string]any, path []string) (map[string]any, error)

// ---- encvalue.go ----

// encodeValue renders one value as its canonical RHS text. ErrType for an
// unsupported dynamic type.
func encodeValue(v any) (string, error)

// ---- encode.go ----

// Encode renders a nested map as canonical TOML text (see Behavioral Spec).
func Encode(m map[string]any) (string, error)

func encodeTable(b *strings.Builder, prefix []string, m map[string]any, isRoot bool) error

// ---- main.go ----

func main()
func run(mode string, in io.Reader) string
func flatten(m map[string]any) []string

// ---- errors (declare in lexer.go) ----

var (
	ErrSyntax    = errors.New("toml: syntax error")
	ErrDuplicate = errors.New("toml: duplicate key")
	ErrType      = errors.New("toml: unsupported value type")
)
```

### Export signatures

```go
var _ func(string) (map[string]any, error) = Parse
var _ func(map[string]any) (string, error) = Encode
```

## Behavioral Specification

### `lexer.go` — `lexLine`, `bareKeyOK`

- **`bareKeyOK(s)`** — true iff `s` is non-empty and every rune is
  `A-Z` / `a-z` / `0-9` / `_` / `-`.
- **`lexLine(line)`** — trim ASCII whitespace to get `t`:
  1. `t == ""` or `t` starts with `#` → `(lineBlank, nil, "", "", nil)`.
  2. `t` starts with `[`: it must also **end** with `]` (else `ErrSyntax`). Take
     the inside, trim it; empty → `ErrSyntax`. Split on `.`; trim each segment;
     each must pass `bareKeyOK` (else `ErrSyntax`). →
     `(lineHeader, segments, "", "", nil)`.
  3. Otherwise: find the first `=`. None → `ErrSyntax`. `key` = trimmed text
     before it, `rawValue` = trimmed text after it. `bareKeyOK(key)` must hold;
     `rawValue` must be non-empty. → `(lineKV, nil, key, rawValue, nil)`.
- `lexLine` does **not** strip a trailing `#` comment — that is why `k = 1 # x`
  fails (its `rawValue` is `1 # x`).

### `strvalue.go` — `unquote`, `quoteString` (see the strvalue Cross-Bead Contract)

- **`unquote(s)`** — `s` must be at least `""` (two chars) and start and end
  with `"` (else `ErrSyntax`). Scan the body byte by byte:
  - a raw newline byte → `ErrSyntax`
  - a raw `"` byte → `ErrSyntax` (it would have ended the string early)
  - `\` → read the next byte: `n`→newline, `t`→tab, `"`→`"`, `\`→`\`; anything
    else (including end-of-string) → `ErrSyntax`
  - any other byte → itself
- **`quoteString(s)`** — emit `"`, then for each byte: `\`→`\\`, `"`→`\"`,
  newline→`\n`, tab→`\t`, everything else unchanged; then `"`.
- These are exact inverses: `unquote(quoteString(x)) == x` for every string `x`,
  and `quoteString(unquote(q)) == q` for every `q` that `unquote` accepts.

### `scanvalue.go` — `scanValue`, `scanInt`, `scanArray`, `splitTopLevel`

- **`scanValue(raw)`** — trim `raw`; empty → `ErrSyntax`. Then dispatch on the
  whole trimmed string:
  - exactly `true` → `true` (bool); exactly `false` → `false`
  - first byte `"` → `unquote(raw)`
  - first byte `[` → `scanArray(raw)`
  - otherwise → `scanInt(raw)`
- **`scanInt(raw)`** — strip one optional leading `-`; the rest must be
  non-empty and all digits; reject a leading `0` when length > 1 (`007`); then
  `strconv.ParseInt(raw, 10, 64)` — any error (including overflow) → `ErrSyntax`.
- **`scanArray(raw)`** — `raw` starts with `[`; it must end with `]`. Inner text
  trimmed; empty → `[]any{}`. Otherwise `splitTopLevel(inner)`, then for each
  part: trim; empty → `ErrSyntax`; `scanValue(part)`; if the result's dynamic
  type differs from element 0's → `ErrSyntax`. (`[]any` is one type regardless of
  contents, so `[[1],[2,3]]` is homogeneous.)
- **`splitTopLevel(s)`** — walk `s`; track `depth` (`[`/`]`) and `inStr` (a `"`
  that isn't preceded by `\`). Split on a `,` only when `depth == 0` and not
  `inStr`. Unbalanced `[`/`]` or an unterminated string → `ErrSyntax`. A final
  field that is all-whitespace (the trailing comma case) is dropped.

### `parse.go` — `Parse`, `descend`

- **`Parse(doc)`** — split `doc` on `\n`. `root := map[string]any{}`;
  `current := root`; `seenHeaders := map[string]bool{}`. For each line
  (1-indexed as `n`):
  - `lexLine` error → return `fmt.Errorf("line %d: %w", n, err)`.
  - `lineBlank` → skip.
  - `lineHeader` with segments `path`: let `hp = strings.Join(path, ".")`. If
    `seenHeaders[hp]` → `line n: ErrDuplicate`. Set `seenHeaders[hp] = true`.
    `current, err = descend(root, path)` (propagate error with the line
    number).
  - `lineKV` with `key`, `raw`: if `key` already in `current` → `line n:
    ErrDuplicate`. `v, err = scanValue(raw)` (propagate with line number).
    `current[key] = v`.
  - Return `root`.
- **`descend(root, path)`** — start `m := root`. For each segment: if `m[seg]`
  is absent, create `m[seg] = map[string]any{}` and step into it; if it is a
  `map[string]any`, step into it; if it is **any other type** → `ErrDuplicate`
  (a header path is crossing a scalar). Return the final `m`.
- Errors always carry a `line N:` prefix via `%w`, so `errors.Is(err,
  ErrSyntax)` / `ErrDuplicate` still work.

### `encvalue.go` — `encodeValue`

- **`encodeValue(v)`** — switch on dynamic type:
  - `string` → `quoteString(v)`
  - `int64` → `strconv.FormatInt(v, 10)`
  - `bool` → `"true"` / `"false"`
  - `[]any` → `encodeValue` each element, join with `", "`, wrap in `[` `]`
  - anything else → `ErrType`

### `encode.go` — `Encode`, `encodeTable` (see the encode -> parse Cross-Bead Contract)

- **`Encode(m)`** — call `encodeTable(&b, nil, m, isRoot=true)`, then ensure the
  result ends with exactly one `\n` (empty string stays empty).
- **`encodeTable(b, prefix, m, isRoot)`** — partition `m`'s keys into `scalars`
  (value is not a `map[string]any`) and `tables` (value is). Sort each list.
  - If `!isRoot`: if `b` already has content, write a `\n`; then write
    `"[" + strings.Join(prefix, ".") + "]\n"`.
  - For each scalar key (sorted): write `key + " = " + encodeValue(value) +
    "\n"` (propagate `ErrType`).
  - For each table key (sorted): recurse with `prefix = append(prefix, key)`,
    `isRoot=false`.
- Canonical form, therefore: root scalars first (sorted), then every table
  depth-first with table names sorted at each level, a blank line before each
  `[header]`, `key = value` with single spaces, a single trailing newline. A
  table with no scalar keys still emits its `[header]` line.

### `main.go` — the CLI (see the cli Cross-Bead Contract)

- **`run(mode, in)`** — read all of `in`; `Parse` it; on error return
  `"error: " + err.Error()`.
  - `mode == "reformat"` → `Encode` the map (on error return `"error: " + …`);
    return the result with the trailing `\n` trimmed.
  - `mode == "dump"` → return `strings.Join(flatten(m), "\n")`.
  - any other mode → `"error: unknown mode " + mode`.
- **`flatten(m)`** — depth-first, keys sorted at each level; for every **leaf**
  (non-map) value emit one line `dotted.path + " = " + typeLabel + ":" +
  encodeValue(value)` where `typeLabel` is `string` / `int64` / `bool` /
  `array`. An empty table contributes no lines.
- **`main`** — `mode` is `os.Args[1]` (default `"reformat"`); print
  `run(mode, os.Stdin)` followed by a newline.

## Cross-Bead Contracts

### strvalue -> scanvalue, encvalue (format)

- **type**: format
- **producer**: `strvalue`
- **consumer**: `scanvalue`, `encvalue`
- **interface**: `unquote(s string) (string, error)` and
  `quoteString(s string) string`. The escape set is **exactly** `\n \t \" \\`.
  `unquote` errors on any other backslash escape, an unescaped interior `"`, a
  literal newline, or a missing closing quote. They are exact inverses (see
  Behavioral Specification → `strvalue.go`).
- **notes**: `scanvalue` calls `unquote` for a value whose first byte is `"`.
  `encvalue` calls `quoteString` for a `string` value. Neither re-implements the
  escape table.

### encode -> parse (format — round-trip)

- **type**: format
- **producer**: `encode`
- **consumer**: `parse`
- **interface**: the canonical TOML grammar in Behavioral Specification →
  `encode.go` and the parse rules in `parse.go`. For every nested map `m` whose
  leaf values are all in the supported domain (see the parse -> encode Cross-Bead Contract):
  `Parse(Encode(m))` returns nil error and a map `reflect.DeepEqual` to `m`.
  For every document `s` that `Parse` accepts: `Encode(Parse(s))` returns the
  canonical form, and `Encode(Parse(Encode(Parse(s))))` equals
  `Encode(Parse(s))` (idempotent).
- **notes**: `Encode` must never emit anything `Parse` rejects — no inline
  comments, no `+`, no unquoted string values, keys always bare (guaranteed
  because a map key that isn't `bareKeyOK` cannot have come from `Parse`; a
  hand-built map with a non-bare key is out of scope). The integration bead owns
  the round-trip assertions in both directions.

### parse -> encode, cli (data-shape — value domain)

- **type**: data-shape
- **producer**: `parse`
- **consumer**: `encode`, `cli`
- **interface**: a value in a parsed map is always one of: `string`, `int64`,
  `bool`, `[]any` (homogeneous by dynamic type), `map[string]any` (nested
  table). No `int`, no `float64`, no `nil`, no other type.
- **notes**: `encodeValue` switches on exactly `string` / `int64` / `bool` /
  `[]any` and returns `ErrType` for the `default` case. `flatten` (cli) labels
  the four leaf types as `string` / `int64` / `bool` / `array`. A test that
  hand-builds a map to feed `Encode` must use `int64`, not `int`, for integers.

### lexer -> parse (protocol)

- **type**: protocol
- **producer**: `lexer`
- **consumer**: `parse`
- **interface**: `lexLine(line string) (kind lineKind, path []string, key string, rawValue string, err error)`.
- **notes**: `Parse` calls `lexLine` once per physical line and dispatches on
  `kind`; it does not classify lines itself. A `lexLine` error is wrapped with
  `fmt.Errorf("line %d: %w", n, err)` and returned.

### scanvalue -> parse (protocol)

- **type**: protocol
- **producer**: `scanvalue`
- **consumer**: `parse`
- **interface**: `scanValue(raw string) (any, error)`.
- **notes**: `Parse` passes each `lineKV` `rawValue` to `scanValue` and stores
  the result. A `scanValue` error is wrapped with the line number.

### cli -> parse, encode (protocol — command dispatch)

- **type**: protocol
- **producer**: `cli`
- **consumer**: `parse`, `encode`
- **interface**: `run(mode string, in io.Reader) string`. `mode` is `"reformat"`
  or `"dump"`. Both first `Parse` all of `in`; a parse error returns
  `"error: " + err.Error()`. `reformat` then `Encode`s (encode error →
  `"error: " + …`) and returns the output with the trailing newline trimmed.
  `dump` returns `strings.Join(flatten(m), "\n")`. Unknown mode →
  `"error: unknown mode " + mode`.
- **notes**: `main` prints `run(...)` plus a newline. Every error line begins
  with the literal `"error: "`.

## Decomposition Notes

**Bead dependency order (do not reorder):**

1. **lexer** — `lexLine`, `bareKeyOK`, `type lineKind` + its constants, the
   three sentinel errors. No dependencies. Owns `lexer.go`.
2. **strvalue** — `unquote`, `quoteString`. No dependencies. Owns `strvalue.go`.
3. **scanvalue** — `scanValue`, `scanInt`, `scanArray`, `splitTopLevel`.
   Depends on bead 2. Owns `scanvalue.go`.
4. **parse** — `Parse`, `descend`. Depends on beads 1 and 3. Owns `parse.go`.
5. **encvalue** — `encodeValue`. Depends on bead 2. Owns `encvalue.go`.
6. **encode** — `Encode`, `encodeTable`. Depends on bead 5. Owns `encode.go`.
7. **cli** — `main`, `run`, `flatten`. Depends on beads 4 and 6. Owns `main.go`.
   sizing rationale: `run` is a two-branch switch over already-tested library
   calls; `flatten` is one sorted depth-first walk; no shared assembly.
8. **integration** — the round-trip both directions plus one CLI reformat.
   Depends on beads 4, 6, 7.

**Integration bead scenario (bounded):**

- Build this map and assert `reflect.DeepEqual(m, Parse(Encode(m)))`:
  `{"s": "he said \"hi\"", "i": int64(-100), "b": false, "arr": []any{int64(1),
  int64(2)}, "srv": {"host": "h", "deep": {"k": int64(9)}}}`.
- Assert `Encode(Parse(x)) == x` for `x =`
  `"a = 1\nb = true\n\n[t]\nk = \"v\"\n"`.
- Feed this exact document to `run("reformat", …)` and assert the exact output
  (no trailing newline):
  ```
  b = 2
  a = 1

  [t]
  k = "x"
  ```
  becomes
  ```
  a = 1
  b = 2

  [t]
  k = "x"
  ```

- **Pin — `strvalue` bead, the escape set (verbatim, must be followed exactly,
  not re-derived):** the only escapes are `\n` `\t` `\"` `\\`. `unquote("a\nb")`
  (with a literal backslash-n in the source) → the two chars `a`, newline, `b`.
  `unquote` errors on: any other `\x`, an unescaped interior `"`, a literal
  newline byte, a missing closing `"`. `quoteString` escapes exactly
  `\`, `"`, newline, tab — nothing else. `unquote` and `quoteString` are exact
  inverses.
- **Pin — `scanvalue` bead, integer + array rules (verbatim):** integer is
  `-?[0-9]+` with no `+`, no `_`, no leading zero past a lone `0` (`007` →
  `ErrSyntax`), `int64` range (`9223372036854775808` → `ErrSyntax`); `-0` → 
  `int64(0)`. Arrays are one line, comma-separated, one optional trailing comma
  allowed, `[]` valid; homogeneous by Go dynamic type with `[]any` as a single
  type (`[[1],[2,3]]` valid, `[1,"a"]` → `ErrSyntax`). `1.5` → `ErrSyntax`.
- **Pin — `parse` bead, duplicate + nesting rules (verbatim):** same bare key
  twice in a table → `line N: ErrDuplicate`; same `[header]` string twice →
  `line N: ErrDuplicate`; a `[header]` path crossing a key already bound to a
  scalar → `line N: ErrDuplicate`; two **different** header strings that share a
  prefix are allowed (`[a.b]` then `[a]`). Keys before the first header land in
  the root map. Every error carries a `line N:` prefix via `%w`. Inline comment
  (`k = 1 # x`) → `line N: ErrSyntax`.
- **Pin — `encode` bead, canonical form (verbatim, must be followed exactly):**
  root scalar keys first, sorted; then nested tables depth-first with table
  names sorted at each level; a blank line immediately before each `[header]`
  line; `key = value` with exactly one space each side of `=`; a table with no
  scalar keys still emits its `[header]`; the whole output ends with exactly one
  `\n`; `Encode({})` is `""`. `encodeValue` returns `ErrType` for any dynamic
  type other than `string` / `int64` / `bool` / `[]any` (so a Go `int` or
  `float64` in the map → `ErrType`).
- **Pin — `cli` / `integration` beads, output (verbatim):** `run` returns
  `"error: " + err.Error()` on any Parse/Encode failure; `reformat` output has
  its trailing newline trimmed; `dump` lines are `path = type:value` with
  `type` one of `string` / `int64` / `bool` / `array`, sorted, empty tables
  omitted. `main` prints the result plus one newline.
